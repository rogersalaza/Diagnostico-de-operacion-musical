# Diagnóstico de operación musical

Cuestionario en línea de **Rogelio Salazar A.I. Solutions** para disqueras, editoras, grupos, artistas, compositores, estudios y rentadoras de equipo.

- 5 pasos, pensado para celular.
- Calcula un puntaje de complejidad y recomienda un paquete (Básico, Operativo o Integral).
- Al final, el cliente envía el resumen por WhatsApp.
- No guarda respuestas en ningún servidor.

Para cambiar el número de WhatsApp o el nombre, edita las líneas `WHATSAPP` y `AGENCIA` al inicio del script en `index.html`.
